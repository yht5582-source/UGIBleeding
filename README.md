# UGIB 急性上消化道出血風險分級計算機

這是一個基於 **ACG (美國腸胃科學會) 2021 年最新指引** 以及 **國際共識** 開發的互動式單頁網頁應用程式 (PWA)。旨在協助急診醫師與胃腸肝膽科醫師，快速評估急性上消化道出血 (UGIB) 患者的死亡、再出血及需要臨床介入（如輸血、內視鏡止血或手術）的風險，進而決定病患應採取門診追蹤或緊急住院。

## 專案特色

*   **雙重評估系統**：整合目前國際最推薦的 **Glasgow-Blatchford Score (GBS)** 與 **Pre-endoscopic Rockall Score**。只需輸入一次病患的生命徵象與抽血數據，系統即可同步算出兩種分數。
*   **指引導向決策**：自動將 GBS 分數對應至 ACG 指引建議。明確標示出 GBS ≤ 1 的「極低風險」族群，協助急診有效分流，減少不必要的住院與醫療資源浪費。
*   **純前端端側運算**：採用 Vue.js 3 進行即時狀態管理與運算。所有運算皆在裝置本地端完成，無伺服器端資料存儲，嚴格保障病患隱私，符合 HIPAA 等醫療資訊規範。
*   **響應式與 PWA 支援**：使用 Tailwind CSS 打造跨裝置友善的 UI，支援在智慧型手機或平板上直接「加入主畫面」成為獨立 App 運行，方便急診室高壓環境下快速點選使用。

## 醫學決策邏輯

### 1. Glasgow-Blatchford Score (GBS)
GBS 是目前公認在「內視鏡檢查前」預測需要臨床介入（輸血、內視鏡止血、手術）準確度最高的工具。評分項目包含：
*   **血液數據**：血清尿素氮 (BUN)、血紅素 (Hb)。
*   **生命徵象**：收縮壓 (SBP)、心跳 (Pulse)。
*   **病史與症狀**：解黑便 (Melena)、暈厥 (Syncope)、肝臟疾病、心臟衰竭。
*   **臨床處置建議**：
    *   **極低風險 (Score ≤ 1)**：不需要緊急介入，強烈建議採門診處置及門診胃鏡檢查。
    *   **中高風險 (Score > 1)**：建議住院觀察，並於 24 小時內安排早期內視鏡檢查 (Early Endoscopy)；若分數極高則需立即穩定血流動力學並評估緊急內視鏡。

### 2. Pre-endoscopic Rockall Score
在尚未進行內視鏡評估潰瘍特徵前，僅利用臨床指標（年齡、休克狀態、共病症）來預測患者的死亡率與再出血風險。
*   分數為 0 代表預後極佳。
*   分數越高，死亡與再出血風險呈現非線性遞增。

## 檔案結構

*   `ugib-calculator.html`: 包含 HTML 結構、Tailwind 樣式、Vue 運算邏輯與 PWA 動態 Manifest 的完整單一檔案。
*   `README.md`: 本說明文件。

## 部署與使用方式

本應用程式採零相依性 (Zero Dependencies) 設計：

1.  將 `ugib-calculator.html` 檔案上傳至任何支援靜態網頁代管的伺服器（例如：GitHub Pages、醫院內部 Web Server）。
2.  在手機或平板的瀏覽器中開啟該網址。
3.  **安裝為 APP**：在瀏覽器選單中點選「加入主畫面 (Add to Home Screen)」，即可在桌面建立捷徑，享受無網址列的全螢幕操作體驗，甚至支援斷網情況下的離線使用（快取載入後）。

## 聲明與免責條款

本互動網頁僅為臨床決策輔助工具 (Clinical Decision Support Tool)。急診情境瞬息萬變，病患的實際處置需綜合考量其動態血流動力學變化、臨床醫師的直覺判斷 (Clinical Gestalt) 以及醫院當下的資源量能。本工具產出之結果絕對不能取代現場主治醫師的專業醫療判斷。
